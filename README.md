# 四つ巴

あっち向いてホイを土台にした、スマートフォン向けの対戦ゲーム。単一HTML・通信不要・インストール不要。

## ▶ 遊ぶ

**https://myzunota.github.io/tomoe_lookthisway/**

上記URL(GitHub Pages)からそのまま遊べます。スマートフォン/PCの両方に対応しています。

## 遊び方

四方向にそれぞれ数があり、攻めと守りが同時に一方向を選ぶ。

- 向きが一致すれば、攻めがその数だけ得点する
- 外れれば、守りが逃げた方角の数だけ**気**を得る。気が満ちれば攻守が交代する
- 取られなかった方角は毎ラウンド1ずつ増え、6に達すると「満」になる。次のラウンドでも取られなければ**破裂**し、他の三方角へ散らばりながら攻め側に加点する
- 盤は毎ラウンド回転する
- 先に規定点(10/12/16点、開始画面で選択)を取った方が勝ち

持ち時間は3秒固定。対戦相手の強さは初伝・中伝・皆伝の3段階から選べ、皆伝はプレイヤーの選択の癖を学習して読んでくる。

## 特徴

- 外部依存のない単一HTMLファイル。ダウンロードすればオフラインでも遊べます
- ブラウザの保存機能は使用していません(localStorage等不使用)。対局結果は保存されず、開くたびに新しい一局が始まります
- 開始画面から「手ほどき」で図解のチュートリアルを見られます
